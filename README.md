# Считалка

Тренажёр вычислений для 4–9 классов: 48 тем, три уровня сложности, смешанные тренировки, подсказки и пошаговые решения. Раздел «Теория и формулы» содержит 18 коротких уроков с правилами, примерами, типичными ошибками и переходом к связанным тренировкам.

## Аккаунты и сохранение

- Ученик регистрируется по логину, паролю и классу. Никнейм используется как имя профиля; логин нормализуется без учёта регистра.
- Пароль сохраняется только в виде хеша `scrypt` со случайной солью. Сессия хранится в подписанном HTTP-only cookie.
- Прогресс, плюсики, искры, кубки, класс, купленные и выбранные оформления сохраняются в MySQL и доступны с телефона и компьютера.
- Открытая страница обновляет облачное состояние каждые 15 секунд. Ответы отправляются последовательно, а UUID попытки не даёт записать один ответ дважды.
- При первом входе локальный прогресс браузера один раз объединяется с облачным. После успешного переноса локальная копия удаляется; повторный импорт не выполняется.
- Без аккаунта продолжает работать гостевой режим с `localStorage`. Выход очищает данные профиля с экрана, чтобы на общем устройстве мог войти другой ученик.
- Все операции с прогрессом и наградами используют пользователя из серверной сессии. Идентификатор другого пользователя нельзя передать из интерфейса или запроса.

## Прогресс, зачёт и плюсики

- Для зачёта по теме нужно решить 20 заданий и набрать не менее 80% ответов с первой попытки без подсказок.
- Зачётный прогресс начисляется только на уровнях «Уверенно» и «Сложно». «Разминка» остаётся свободной практикой и учитывается только в общей статистике.
- В смешанной тренировке каждый зачётный ответ засчитывается в тему конкретного задания.
- За первый настоящий зачёт каждой темы начисляется ровно один плюсик. Повторное прохождение и повторный перенос не выдают награду снова.
- Плюсики не отнимаются за ошибки, перерывы или сброс статистики. Сброс прогресса также сохраняет покупки и отметки о выданных наградах.
- Нет лотерей, случайных наград, покупки валюты за деньги, штрафов за пропуски и истекающих достижений.

## Сетевая арена, искры и домашние работы

- Комната объединяет 3–8 зарегистрированных учеников. Все получают одинаковые 10 заданий, сервер задаёт общий 4-секундный отсчёт и 90-секундный финиш.
- Ответ принимается один раз и не перезаписывается. До финиша правильные ответы скрыты, после финиша доступен разбор.
- Сначала сравнивается число правильных ответов, затем время последнего отправленного ответа. Первые три места получают постоянные золотой, серебряный или бронзовый кубок и 5/3/2 искры.
- Остальные участники, ответившие на все задания, получают 1 искру. Участники без ответов наград не получают. Повторное завершение комнаты не дублирует награды.
- Учитель с admin-ролью вручную подтверждает домашнюю работу и выдаёт 1–20 искр с комментарием. UUID награды не даёт начислить одну работу дважды; обычному ученику эта операция недоступна.
- Искры и плюсики — разные валюты. Их нельзя купить за деньги; нет лотерей, штрафов и случайных выпадений.

## Мастерская оформления

Классическая тема бесплатна. Остальные темы можно предварительно примерить, открыть за указанную валюту и затем свободно переключать без повторной оплаты:

| Оформление | Цена |
| --- | ---: |
| «Сакура//Неон» | 3 плюсика |
| «NOIR · Чёрная тетрадь» | 4 плюсика |
| «Мятный комикс» | 2 плюсика |
| «Космический разряд» | 5 плюсиков |
| «Персиковый ритм» | 3 плюсика |
| «LIME//Арена» | 6 искр |
| «CORAL//Разряд» | 8 искр |
| «STICKER//Поп» | 10 искр |

Девять тем меняют фон, панели, кнопки, карточки, прогресс, акценты и аксессуар кота. Упражнения и формулы остаются на своих местах. Покупка и списание нужной валюты выполняются атомарно на сервере.

## Разработка

```bash
npm install
npm run dev
npm run check
npm run test
npm run build
npm start
```

Для разработки схемы используется `npm run db:push`. Для production-миграций — `npm run db:generate` и `npm run db:migrate` после проверки созданной миграции.

Стек: React, TypeScript, Vite, KaTeX, Hono, tRPC, Drizzle ORM и MySQL. Для аккаунтов и облачной синхронизации production-серверу нужны Node.js и MySQL; одного статического хостинга недостаточно.

## Запуск в Docker

Образ собирает интерфейс и серверный bundle, но не содержит `.env` или другие секреты. Перед запуском подготовьте MySQL и переменные из `api/lib/env.ts`, затем примените проверенные миграции базы данных.

```bash
docker build -t schitalka .
docker run --rm -p 3000:3000 --env-file .env schitalka
```

Контейнер слушает порт `3000`. Для публичного доступа его нужно разместить на хостинге с поддержкой долгоживущего Node.js-процесса и подключить постоянную базу MySQL. GitHub Pages не может запустить серверную часть, аккаунты и облачную синхронизацию.

# Считалка

Тренажёр вычислений для 4–9 классов: 48 тем, три уровня сложности, смешанные тренировки, подсказки и пошаговые решения.

## Прогресс и зачёт

- Для зачёта по теме нужно решить 20 заданий и набрать не менее 80% ответов с первой попытки без подсказок.
- В смешанной тренировке каждый ответ засчитывается в тему конкретного задания.
- Прогресс хранится только в `localStorage` текущего браузера и не синхронизируется между устройствами.

## Разработка

```bash
npm install
npm run dev
npm run build
```

Стек: React, TypeScript, Vite. Серверная часть и аккаунты не используются.

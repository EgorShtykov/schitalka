# Считалка

Тренажёр вычислений для 4–9 классов: React, TypeScript и Vite.

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

Требуется Node.js 22 или совместимая более новая версия.

```bash
npm run build
```

Публикация на GitHub Pages выполняется автоматически workflow из `.github/workflows/deploy.yml` при обновлении ветки `main`.

Прогресс ученика хранится только в localStorage его браузера и не синхронизируется между устройствами.
